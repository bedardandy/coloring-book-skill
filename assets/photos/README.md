# Sample photos

Open-licensed test inputs for the photo pipeline (`tools/eval_photo.py`
real-photo tier; `dog.jpg` is also the showcase subject for pages 17/18).
Attribution, sources and licenses (both CC BY-SA) are in `../../CREDITS.md`.
Metadata was stripped losslessly; pixels are the Commons originals.

Nothing personal goes here: no family photos, no photos of children. Extra
local test photos belong in a directory outside the repo, passed to the
evaluation as `--photos DIR`.
